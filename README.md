# Freestyle Studio

Freestyle Studio is a Mac app for recording yourself on camera next to your screen, with a teleprompter built in. It needs macOS 14 or newer and runs on both Apple silicon and Intel Macs.

This repo only holds the downloads and update feed. The app's source code isn't here.

## Install

1. Download the zip from the [latest release](https://github.com/agent-tg/curtain-call/releases/latest).
2. Open the zip and drag **Freestyle Studio** into your Applications folder.
3. Open it. When macOS asks for Camera, Microphone and Screen Recording access, allow them. If you denied screen access by mistake, turn Freestyle Studio on in **System Settings → Privacy & Security → Screen & System Audio Recording**, then reopen the app.

## Where your files go

- Put scripts in `~/Movies/Curtain Call/Scripts` as Markdown or text files. You can also make new scripts inside the app.
- Studio takes save to `~/Movies/Curtain Call/Takes`.
- Freestyle screen recordings save to `~/Movies/Curtain Call Walkthroughs`.

Everything stays on your Mac. Recordings don't get uploaded anywhere.

## Updates

Freestyle Studio checks for updates on its own and installs them the next time you quit. You can also check any time from **Freestyle Studio → Check for Updates…**.
