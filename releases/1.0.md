Curtain Call records screen and camera videos on macOS 14 or later.

- Record unscripted walkthroughs in Freestyle or use Studio with a script.
- Studio’s No script option now keeps a separate video title and leaves script settings inactive.
- Studio and Freestyle use the same selected microphone input and recording gain. This fixes quiet Freestyle audio with multi-input interfaces such as the Scarlett.
- Use Check level and speak normally for five seconds to set a fixed recording gain.

Download the ZIP, unzip it, and move Curtain Call to Applications. On first use, allow the camera, microphone and screen-recording access you need.

This release supports Apple Silicon and Intel Macs and includes automatic update checks. Recordings stay local; Google Drive sign-in is not included in this release.
